# Agent 平台

Agent 平台上下文负责版本化定义和可靠执行 AI 工作流。它保存运行事实和证据引用，但不拥有客服会话、订单、服务工单或风险预警。

## 定义

**Agent 定义（Agent Definition）**：
描述一个可运行 AI 能力的稳定身份及其输入输出边界。定义通过已发布版本绑定工作流、模型、Prompt、工具和知识。
_避免使用_：机器人、模型、客服 Agent

**工作流（Workflow）**：
由确定节点和边组成的可恢复执行定义。工作流控制工具和模型的调用顺序，而不是把控制权交给自由工具调用。
_避免使用_：思维链、业务流程

**工具（Tool）**：
Agent 平台可在授权、预算和输入输出契约约束下调用的外部能力。工具不是领域实体的所有者。
_避免使用_：服务、Repository、插件

**知识库（Knowledge Base）**：
可版本化发布并按证据引用检索的非结构化知识集合。实时订单、服务工单和风险状态不属于知识库。
_避免使用_：业务数据库、全部上下文

## 运行与质量

**Agent Run**：
某个已发布 Agent 版本针对一次输入的可审计执行实例。它记录版本快照、节点结果、用量和终态。
_避免使用_：会话、辅助请求

**运行证据（Run Evidence）**：
Agent Run 实际消费和输出的来源引用、检索片段及工具调用摘要。运行证据不复制其所属上下文的业务所有权。
_避免使用_：业务事实、思维链

**评测用例（Evaluation Case）**：
包含固定输入、期望约束和评分方法的可重复质量样本。线上运行输入与隐藏评测标签必须隔离。
_避免使用_：测试聊天、示例 Prompt
